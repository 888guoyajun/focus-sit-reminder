# 专注提醒器 v0.1 商业化发布清单

## 当前可售版本边界

- macOS 和 Windows 本地桌面软件
- 专注倒计时、久坐提醒、稍后提醒、暂停、静音
- 提醒级别根据忽略次数提升
- 设置和统计只保存在用户本机
- 不包含账号、云同步、摄像头识别和硬件拍打

## 每次发布

1. 修改 `desktop/package.json` 的版本号。
2. 在 macOS 机器执行 `npm run dist:mac`。
3. 在 Windows 机器执行 `npm run dist:win`。
4. 在两台系统上分别测试安装、启动、右下角定位、倒计时、暂停、退出和卸载。
5. 记录版本号、构建日期和已知问题。

## 正式销售前

- Apple Developer 签名和公证，避免 macOS Gatekeeper 拦截。
- Windows 代码签名证书，降低 SmartScreen 警告。
- 准备隐私说明：本地保存哪些数据、是否联网、如何删除数据。
- 明确退款、升级和客服方式。
- 健康免责声明：软件只做提醒，不替代医疗建议。
- 选择授权方案：首版建议一次性买断，后续再考虑订阅或设备联动。

## 下一阶段

- 自动更新
- 授权码或订单校验
- 用户可编辑的提醒策略
- 崩溃日志（默认关闭，且需征得用户同意）
- 官网下载页和版本发布记录
